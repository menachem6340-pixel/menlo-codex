# Menlo Build V2 — High-Tech Construction Command Center
## אפליקציה מקבילה עצמאית לעבודת שטח ומשרד (שילוב הייטקי ונוכחות חזקה)

אפליקציה זו נבנתה כפרויקט מקביל לחלוטין ונפרד מהמערכת הפעילה הקיימת של מנלו בנייה (`menlo-claude`), ומאפשרת בחינה, הרצה והטמעה בטוחה ב-0% סיכון.

---

### עקרונות העיצוב והשפה החזותית:
1. **צבעי מותג רשמיים מאומתים:**
   - `#414042`: אפור גרפיט שלד (מבנה, מסגרות וכותרות).
   - `#1b75bc`: כחול מנלו הנדסי (צבע מותג ראשי, ניווט וכפתורי מפתח).
   - `#f3c936`: צהוב-ענבר בטיחותי (נוכחות חזקה בשטח, פעולות בולטות ואבני דרך).
   - `#00a79d`: טורקיז אדריכלי (בקרת איכות ואישורי ביצוע).
2. **שילוב הייטקי ונוכחות חזקה:**
   - מעטפת Dark Slate עמוקה (`#0f172a` ו-`#1e2022`) עם הילות אור מבוקרות בכחול וצהוב.
   - כפתורי טאץ' מוגדלים (56px) למובייל בשטח, קריאים תחת שמש ישירה.
   - לוח בקרה עשיר למשרד המציג אומדן BOQ מול חוזים מול תשלומים בפועל.

---

### המודולים המרכזיים שנבנו:
* **`FieldDailyLog.tsx`**: יומן שטח יומי עם מונה פועלים מהיר (+/-), שלבי יציקה, ותיעוד מצלמה.
* **`GrokVoiceTranscriber.tsx`**: מודול שמע Grok Voice (xAI) לפיענוח הודעות קוליות מוואטסאפ ליומן העבודה.
* **`BudgetCommandCenter.tsx`**: לוח בקרה משרדי המשלב תקציב BOQ מול ביצוע קבלנים.
* **`async-analyze` API Route**: פתרון מוחלט לשגיאות 504 Timeout באמצעות מעבר לעיבוד רקע מהיר.

### מסד נתונים ותור ניתוח

המיגרציה נמצאת תחת `supabase/migrations` ומוסיפה את `project_areas`, את `tasks.area_id`,
ואת טבלת התור `plan_analysis_jobs`. נתיבי ה־API עובדים במצב הדמיה כאשר משתני הסביבה אינם
מוגדרים; כאשר הם מוגדרים, פעולות בעלות עלות או כתיבה מחייבות Bearer token תקף של Supabase.

ל־Grok Voice לא מקודד endpoint או model שלא אומתו. יש להגדיר במפורש את
`XAI_TRANSCRIPTION_URL` ואת `XAI_TRANSCRIPTION_MODEL` בהתאם לחשבון xAI הפעיל.
